# Spielwelt Stable

Stable Spielwelt downloads. Separate from experimental test builds.

## Status

This download channel is being prepared. **No installer or game release is available here yet.**

Only explicitly approved stable versions belong here.

## Downloads and updates

Installers and update packages will be provided as GitHub Release assets, not committed to this repository.
Test and stable installations will use separate update channels and save locations.
There is no automatic switch between test and stable.

The other channel is [spielwelt-test](https://github.com/NathailieRomano/spielwelt-test).

## Repository scope

This is a download-only repository. It does not contain the Spielwelt source code, personal data, or access credentials.
A public download does not grant an open-source license to the game.
